# Shared principles map

Consensus principles that recur across Athlean-X, FMS/Cook, Boyle, Dan John, McGill, Gambetta, EXOS, DNS, and Santana.

## Universal agreements

| Principle | Who emphasizes it | Product implication |
|---|---|---|
| Train patterns, not only muscles | Cook, Dan John, Athlean-X, Boyle, EXOS | Pattern-tagged exercise library |
| Quality / competency before heavy load | Cook, McGill, DNS, Gambetta | Progression gates |
| Mobility before stability before strength/power | Cook, McGill, EXOS pillar prep | Ordered session and program phases |
| Core as stabilizer / force transmitter | McGill, Boyle, Dan John, Gambetta | Anti-movement core defaults |
| Unilateral and multi-plane matter | Boyle, Gambetta, Athlean-X, Santana | Include lunge, carry, rotate — not only bilateral sagittal lifts |
| Progressive overload still rules strength | Athlean-X, Dan John, Boyle | Track load/reps; compounds as anchors |
| Correctives belong in normal training | Athlean-X, Cook, Boyle (as warm-up) | Small daily corrective block |
| Individualization | Gambetta, EXOS, Cook | Onboarding constraints, pain flags, equipment |
| Recovery is part of the system | EXOS, McGill (stages), Athlean | Rest days, sleep/fuel prompts |
| Safer swap if equal outcome | Athlean-X, Boyle, McGill | Substitution engine |

## Where sources diverge (resolve intentionally)

| Topic | Camp A | Camp B | Suggested product default |
|---|---|---|---|
| Bilateral squat centrality | Traditional S&C / some Athlean compounds | Boyle: unilateral primary | Offer both; prefer unilateral for general pop if knee/back flags |
| Olympic lifts | Boyle (hang variants yes) | Many consumer apps avoid | Optional advanced power track |
| Formal movement screen | FMS / SFMA | Dan John / Athlean less formal | Soft checklist v1; certified screen later |
| Flexion-based ab work | Classic bodybuilding | McGill caution for symptomatic spines | Prefer anti-extension/rotation; allow flexion if pain-free goal is hypertrophy |
| Complexity of methods | EXOS / WARRIOR advanced tools | Dan John Easy Strength | Start simple; unlock complexity by level |

## One shared sentence

**Build clean fundamental patterns and a stiff, enduring midsection; load those patterns progressively across push, pull, hinge, squat/lunge, and carry; add power and conditioning only after the base holds; keep correctives and recovery in the plan.**
