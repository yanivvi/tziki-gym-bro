# Training hierarchy

Shared progression model for assessment, programming, and safety gates.

## Layer stack (bottom → top)

```
6. Sport skill / open skill expression
5. Speed, power, agility
4. Strength (loaded patterns)
3. Work capacity / pattern endurance
2. Stability + motor control (incl. core stiffness)
1. Mobility + tissue access (needed ROM)
0. Pain status / medical clearance
```

Never skip upward when a lower layer is broken for the task.

## Operational gates for an app

### Hard gates

- User reports sharp/radiating pain → stop loading; show “see a professional” path; offer only pain-free mobility/breathing options if any.
- Cannot hip-hinge with neutral spine intent → do not prescribe loaded conventional deadlift; regress to hip-hinge drills / glute bridge / trap-bar or cable hinge as appropriate.

### Soft gates

- Limited overhead ROM → prefer landmine / incline push over strict press until mobility improves.
- Poor single-leg balance → shorten lunge ROM or use assisted split squat before walking lunges.
- Beginner flag → Easy Strength style: few patterns, moderate loads, high practice frequency.

## Corrective priority (Cook-inspired, simplified)

1. Clear breathing / ribcage and pelvic organization if obviously dysfunctional (advanced; optional).
2. Restore limiting mobility (e.g. ankle, hip, T-spine, shoulder).
3. Own stability in the new ROM (dead bug, side plank, bird dog, pallof).
4. Rehearse the pattern unloaded or lightly loaded.
5. Load the pattern.
6. Add speed/power.

## Session-level hierarchy (EXOS-lite)

1. **Prep** — soft tissue optional, mobility, activation
2. **Power** — jumps/throws/swings (if goal and readiness allow)
3. **Strength** — primary patterns
4. **Accessory / corrective**
5. **Conditioning** — if scheduled
6. **Regen note** — cool-down, walk, breathing

Power before heavy strength when both are in the same session (fresh nervous system), unless the program is strength-primary and power is a light primer.
