# EXOS (Athletes’ Performance)

## Who / what

EXOS (formerly Athletes’ Performance): large performance system used with elite and tactical populations. Strong on session architecture and holistic “gameplan” (training + fueling + sleep + recovery).

## Core ideas to keep

- Session components often include:
  - Pillar Prep (soft tissue, mobility, stability for shoulders/torso/hips)
  - Movement Prep (dynamic stretch, activation, neural prep)
  - Ballistics (plyometrics + med ball)
  - Strength and Power
  - Movement Skills (acceleration, multi-directional, absolute speed)
  - Energy Systems Development (ESD)
  - Regeneration
- Position → Pattern → Power readiness frame.
- Work + Rest = Success; recovery is programmed, not optional.
- Rotation as a foundational human movement theme in newer XPS framing.
