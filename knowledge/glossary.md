# Glossary

| Term | Meaning in this KB |
|---|---|
| **Pattern** | A fundamental human movement category (hinge, squat, push, etc.), not a single exercise |
| **Corrective** | Low-load work to restore mobility, stability, or motor control that limits a pattern |
| **Functional training** | Training organized around real-world or sport movement demands and quality patterns — not synonymous with unstable-surface tricks |
| **Pillar** | EXOS term for shoulders–torso–hips as the movement support structure |
| **Movement prep** | Dynamic warm-up and activation before main work |
| **ESD** | Energy Systems Development — structured conditioning |
| **FMS** | Functional Movement Screen — standardized movement screen (Gray Cook / Lee Burton) |
| **SFMA** | Selective Functional Movement Assessment — clinical assessment when pain is present |
| **DNS** | Dynamic Neuromuscular Stabilization — developmental kinesiology–based system |
| **Anti-extension** | Core work resisting lumbar extension (e.g. dead bug, ab wheel with control) |
| **Anti-rotation** | Core work resisting twist (e.g. pallof press) |
| **Anti-lateral flexion** | Core work resisting side bend (e.g. suitcase carry, side plank) |
| **Hip hinge** | Hip-dominant pattern keeping roughly neutral spine while hips move back/forward |
| **Loaded carry** | Walking (or marching) while holding load; trains posture, grip, trunk |
| **Same but different** | Dan John idea: rotate close variations of a pattern to progress while managing joints |
| **Stone / hammer** | McGill/Dan John metaphor: stable trunk structure (stone) vs force expression (hammer) |
| **Progressive overload** | Gradual increase in demand (load, reps, density, complexity) over time |
| **Regression / progression** | Easier or harder exercise in the same pattern family |
| **Unilateral** | One-limb or split-stance dominant work |
| **Bilateral** | Both limbs sharing the load symmetrically |
| **Axial loading** | Load compressive through the spine (e.g. back squat, heavy conventional deadlift) |
| **RPE / RIR** | Rate of Perceived Exertion / Reps In Reserve — effort autoregulation tools |
