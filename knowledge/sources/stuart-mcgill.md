# Stuart McGill — Spine performance and default patterns

## Who / what

Stuart McGill: spine biomechanics researcher (University of Waterloo) and performance consultant. Work underpins modern “spare the spine, build stiffness, then load” coaching.

## Core ideas to keep

- Build motion/motor patterns and joint stability/endurance before maximal strength and speed.
- Create strong default patterns, then strengthen them with load.
- Super-stiffness: train the torso to create a stable platform for limb force (stone), then express power (hammer).
- Five-stage ultimate back approach (from *Ultimate Back Fitness and Performance*):
  1. Groove motion / motor patterns
  2. Build whole-body and joint stability (super stiffness)
  3. Increase endurance
  4. Build strength
  5. Develop speed, power, agility
- Classic practical tools often associated with McGill education: bird dog, side plank, modified curl-up (Big 3), bracing, hip-hinge competence.

## Product extraction

- Default core prescription: endurance and bracing before high-rep flexion crunch culture.
- Gate heavy axial loading behind hinge competency and pain-free status.
- Separate “core endurance / stiffness” intent from “abdominal hypertrophy” intent in exercise metadata.
- Never present McGill material as diagnosing user back pathology in-app.
